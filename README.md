# Shindo Toolkit

[Русская версия](README.ru.md)

The script is designed to provide only basic and stable QOL and FUN features. No automated actions or features relating to PVP will be provided.

## Loader

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/main/loader.luau"))()
```

## Dev Loader

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/dev/loader.dev.luau"))()
```

The dev version may contain unstable, unfinished, or not yet tested changes.

## Planned Future Features

- [ ] Protection against scripts used by players who use powerful exploits.
- [ ] FUN features
- [ ] In the future, considering adding all known Shindo exploits as an optional plug-in feature (Pro Rank automation and PvP functions would clearly be a significant advantage, so they will not be included)
