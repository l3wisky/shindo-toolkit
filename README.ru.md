# Shindo Toolkit

[English version](README.md)

Этот скрипт в основном предоставляет базовые функции, улучшающие качество жизни, доступные большинству игроков в Shindo Life, и не предназначен для получения преимущества касательно PvP. 

## Лоадер

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/main/loader.luau"))()
```

## Dev-лоадер

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/dev/loader.dev.luau"))()
```

Dev-версия может содержать нестабильные, незавершённые или ещё не протестированные изменения.

## KGCHANGER

Упрощает использование известной уязвимости, которая доступна и без скрипта.

В обычных сценариях тот же результат можно повторить через известный тайминг `Load Loadout`. KGCHANGER просто делает это поведение намного удобнее.

## RCGENKAI

Позволяет приобрести любой re-skin bloodline в RELLshop приблизительно за 300 000–500 000 RELL Coins, не дожидаясь специальных ивентов.

## MISC

- Позволяет загрузить желанные outfits в любом месте, не переходя в Home.
- DATA MANIPULATION. Предоставляет всем известную базовую функцию отката прогресса (затрагивает любой прогресс, включая RC и Spins, но не прогресс в leaderboard). Используется игроками с очень давних времён для выбивания желаемых рас/бладлайнов, выдачи RC через RELLbloodline, получения огромного Rank или тестирования без траты ресурсов. По умолчанию скрипт не предоставляет автоматизации, связанной с этой уязвимостью, и не будет.
- Удобный просмотр и использование всех данных/статистики определённого игрока (ЕЩЁ В ПРОГРЕССЕ).
