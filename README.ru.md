# Shindo Toolkit

[English version](README.md)

Скрипт предназначен предоставлять только базовые и стабильные QOL и FUN функции. Автоматизированные действия или функции касательно PVP предоставлены не будут.

## Лоадер

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/main/loader.luau"))()
```

## Dev-лоадер

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/l3wisky/shindo-toolkit/dev/loader.dev.luau"))()
```

Dev-версия может содержать нестабильные, незавершённые или ещё не протестированные изменения.
