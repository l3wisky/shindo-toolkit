# Security policy

## Supported versions

Only the latest published 1.x release and the current `dev` branch receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a loader, dependency, workflow, credential, or release-chain vulnerability. Use a
[private GitHub security advisory](https://github.com/l3wisky/shindo-toolkit/security/advisories/new) and include:

- affected version or commit;
- minimal reproduction and expected impact;
- whether the problem is in Shindo Toolkit, Rayfield, an Action, or the target game integration;
- a suggested mitigation, if known.

Do not include Roblox credentials, executor keys, private-server codes, GitHub tokens, or another person's data.
Ordinary compatibility failures and missing game targets belong in the public bug-report form and should include
the privacy-safe Diagnostics output.

The project will acknowledge a valid report when the maintainer reviews it, coordinate a fix privately when
needed, and credit the reporter unless anonymity is requested. No response-time guarantee is made for this
noncommercial project.
